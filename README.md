# Peter Akomaye — Humanitarian Portfolio

A responsive four-page portfolio built with HTML, CSS, and vanilla JavaScript.

## Pages
- Home — mission, introduction, and featured initiatives
- About — values and humanitarian approach
- Projects — A Chance to Dream and skills-acquisition training for 300 girls
- Contact — partnership, project, volunteering, and WhatsApp contact prompts

## Configure WhatsApp
Open `script.js` and replace `234XXXXXXXXXX` with Peter's WhatsApp number in international format, using digits only. For a Nigerian number, replace the leading 0 with 234. Example format: `2348012345678`.

Until a real number is configured, WhatsApp buttons direct visitors to the Contact page instead of opening a broken link.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Deploy
The site can be deployed directly to GitHub Pages, Netlify, or Vercel as a static site.
